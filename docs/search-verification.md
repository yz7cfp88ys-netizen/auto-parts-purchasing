## 后台、报价、付款与隐私

同一浏览器代找请求在后台实际操作 located→创建专属商品订单→填写明确标记的合成报价→发布私有客户链接→客户确认整单。

- 订单：`PO-20261018-9F8BB3F2C64ABE80`。
- 合成报价：3 × $12.50 + $5.00 运费 = $42.50；这些仅为隔离测试值，不是实际售价。
- 客户可通过专属链接查看并确认最新报价；私有商品不出现在公开目录。
- PayPal 未配置，点击全款支付实际返回 503，并显示 `PayPal is not configured. No payment has been taken`；订单未被标记为已付款，没有模拟商户接口。
- 浏览器控制台相应的 503 是这次故意验证未配置付款的预期结果，不应报告为“付款成功”或“全程零网络错误”。
- 图片路径位于 public_html 外；未授权后台读取返回 401；假冒 PNG 的脚本被服务端拒绝；上传前后 SHA-256 一致；PHP 重启后请求、关联订单和图片引用仍在；SQLite integrity_check 为 ok。
- 浏览器上传工具拒绝读取 D 盘及临时附件路径，因此最终浏览器上传使用页面内 canvas 生成、写入 file input 的测试 PNG。它验证实际表单与服务端上传链，**没有声称实测操作系统文件选择器**。独立 HTTP 测试另验证本地测试文件内容保存一致。
