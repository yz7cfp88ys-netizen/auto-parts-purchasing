# 网站维护说明

## 已实现

英文自适应网站；桌面和手机导航；汽摩配筛选；添加分类到询价；最多 30 行零件；必填项、邮箱和正整数数量验证；询价预览、复制和 UTF-8 文本下载；常见问题折叠；隐私与网站说明弹窗；减少动画偏好支持。无账户、支付、模拟库存或虚构发送成功。

## 发布前确认的业务信息

真实公司和品牌名称、业务邮箱、WhatsApp、正式域名、商业条款与适用地区法律文本尚未提供。现有隐私说明描述实际技术行为，不代替特定司法辖区的法律审查。

## 素材

工作车间照片来自 Unsplash，通过 `https://images.unsplash.com/photo-1486262715619-67b85e0b08d3` 下载到 `source/assets/workshop.jpg`。照片仅说明汽车维修场景，不代表本企业场地、人员或工厂。上线不依赖远程照片加载。

零件类别使用项目内手绘 SVG 线稿，均为示意，不代表具体 SKU、品牌或可供库存。标题字体 Barlow Condensed，正文字体 DM Sans，通过 Google Fonts 加载；离线时使用系统回退字体。

## 关键验证

`npm run check` 检查本地资源、锚点、重复 ID、配置及 JavaScript 语法。`npm test` 覆盖询价校验和导出。`npm run build` 生成静态目录。界面验证需检查桌面、手机、分类筛选、零件增删、无效表单、导出内容和弹窗关闭。
