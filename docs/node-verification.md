# Node.js 版本验证记录 · 2026-10-18

## 当前验证范围

在 D:\AI项目库\auto-parts-purchasing 运行。目标 Node.js 22，本地以官方 Node.js 22.16.0 Windows 二进制执行集成和浏览器测试；下载 SHA-256 与官方 SHASUMS256.txt 一致。数据库为本地专用 MariaDB 11.4.2（MySQL 协议），GitHub Actions 配置使用 MySQL 8.4，远程结果另行记录，不能将本地 MariaDB 写成 Hostinger MySQL 已验收。

本地已验证：

- 数据库真实建表，产品与分类新增 / 编辑 / 搜索 / 下架，分类引用保护。
- scrypt 密码验证、数据库会话、未授权访问阻止、CSRF 与 Origin 校验、生产 Secure Cookie、退出登录后会话失效、登录限流。
- 客户多产品 + 未上架产品事务落库；产品名称由数据库决定，SKU / 名称快照保存。
- 数量 / 邮箱 / 同意存储等输入校验；SQL 注入不改变查询含义；中途明细失败则整单回滚。
- 同一请求并发重试只产生一份询价；同请求号不同内容返回 409。
- 后台检索、明细、规格、状态与内部备注、状态历史以及编辑版本冲突保护。
- 重建 Express 服务和数据库连接池后，询价、状态及管理员会话保留。
- 邮件事务队列、TLS 失败记录、人工重试、通过本地 SMTP 协议服务器实际接收通知，后台状态变为 sent。**本地 SMTP 接收器是自动测试设施，不是正式邮箱收件证据。**
- 真浏览器录入分类和产品，客户选择产品、填写自定义产品与规格、提交回执，后台查看并更新状态，再重启后核对。
- 1440 桌面 / 390 手机无整页横向溢出；后台表格可在区域内横向滚动；恶意 HTML 按文本显示，没有脚本执行或 JS 未捕获异常。
- 构建资产、Node 22 部署配置、私有 / 静态目录边界、内部锚点、响应头及既有询价格式单元测试。
